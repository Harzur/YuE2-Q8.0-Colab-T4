# YuE2 AI Music Generator on Google Colab Free (GGUF Q8_0)

This repository provides a **Google Colab notebook** designed to run the **YuE2 (YuE2-3B)** music generation model using its quantized version in **GGUF format (Q8_0)**. 

Thanks to `yue2.cpp` optimizations and lightweight weights, this notebook allows you to generate full songs with vocals and instrumentation using the free tier of **Google Colab (T4 GPU)** without hitting VRAM memory limits.

## Key Features & Keywords
* **Model:** YuE2 (Next-generation AI music generation)
* **Format:** GGUF quantized to Q8_0 (`YuE2-3B-Q8_0.gguf`)
* **Environment:** Optimized for Google Colab Free / Jupyter Notebook
* **Hardware:** Runs smoothly on a standard T4 GPU
* **Functionality:** Text-to-music, lyrics-to-song, and zero-shot music editing


## Quick summary

1. Open the notebook using the badge above.
2. Make sure your Colab hardware accelerator is set to the free **T4 GPU**  
3. Run the cells in order — the notebook downloads the build from Releases and runs it inside the Colab runtime.
4. Open the WebUI
